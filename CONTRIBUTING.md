# Contributing to Ab Slide Ease

Thank you for your interest in contributing to `ab-slide-ease`! We welcome bug fixes, documentation improvements, and feature proposals.

## 🚀 Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/ab-slide-ease.git
   cd ab-slide-ease
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```

## 🛠️ Development & Building

- Run production build:
  ```bash
  npm run build
  ```
- Test locally using `test-demo.html` in your browser.

## 📝 Pull Request Guidelines

- Keep changes focused and well-scoped.
- Ensure `npm run build` succeeds without compilation errors.
- Provide a clear title and description in your PR explaining the rationale behind changes.
